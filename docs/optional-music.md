# 可选曲库下载

提供不含音频的轻量程序包、按分类拆分的曲包，并保留完整包。左下角“下载曲库”打开可多选的下载窗口，列出每包曲目数、压缩大小、已安装状态；用户选择后才联网。按现有主题与 BP 主赛事分包，交叉赛事用途保留在曲目元数据中。

曲包清单随程序发布，固定 GitHub v0.1 附件地址、长度、SHA-256 和每文件校验值。下载到 Data 内临时目录，校验后才安装。新增曲目合并到现有设置，不覆盖既有收藏、片段、音量、自动播放开关和对局记录。失败或取消清理本次临时文件；保存失败回滚新增曲目和文件。支持手动下载同一曲包 ZIP 后校验导入。

此功能不抓取第三方平台，不承诺实时扩充在线歌曲目录；新增曲目随之后的版本发布。
