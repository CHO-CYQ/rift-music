# 峡谷序曲 v0.1 宣传视频制作单

## 先拍什么

主题：**“还记得那些熟悉的开局音乐吗？我把它们做进了一个小工具。”**

一条视频只讲两个使用场景：进入峡谷听开场；选人时听 BP 配乐。不要从软件名称、技术架构或一长串设置开始。

第一版建议：60–75 秒横版主片，另剪 35–45 秒竖版短片。先用实际录屏做成完整的第一条，再考虑复杂三维片头。

## 横版分镜与口播

| 时间 | 画面 | 口播 / 大字幕 |
| --- | --- | --- |
| 0–4s | 自己录制的峡谷开局，干净画面，接一段已获相应用途许可的熟悉旋律 | “还记得，进峡谷时响起的那段音乐吗？” |
| 4–10s | 白底电蓝切换，软件标题与整体界面出现 | “我做了个小工具，想把熟悉的开场旋律带回来。” |
| 10–22s | 点击世界赛，选年份，试听一首；再切一首英雄 / 皮肤主题 | “世界赛、英雄、皮肤和活动主题，按分类和年份慢慢找。” |
| 22–34s | 同一画面切换到赛事 BP，依次展示 S 赛、MSI、LPL / LCK；只展示真有音源的组合 | “也单独做了 BP 配乐，选人和开场，各有自己的播放计划。” |
| 34–45s | 收藏一首、设置固定曲目、底部播放器推进；鼠标操作少而清楚 | “可以随机，也可以只留一首。收藏、试听，再选好下一局。” |
| 45–57s | 如已验证，展示从选人 / 游戏开始到自动播放的连续实录；否则展示设置并明确写“自动触发待实测” | “目前是 v0.1 测试版，还在收集国服客户端的兼容反馈。” |
| 57–68s | 软件 + GitHub 项目页，收尾停留 3 秒 | “源码和测试版放在 GitHub。你最想找回哪一年的开场？” |

**不能用手动点击试听的镜头冒充自动触发。** 尚未实测就不写“已全面适配国服”“稳定自动播放”。可以先发界面与音乐管理演示，后续实测通过再补一条实机视频。

## 录制清单

1. 自己的训练模式开局连续实录一段；如要展示自动 BP，再录真实选人阶段。保留原始连续素材，剪辑时不要遮掉触发关系。
2. 软件窗口：游戏开场全览、世界赛年份、另一主题、BP 赛事 / 年份、收藏、设置固定、播放器，共 7 个动作，每个动作录 5–8 秒。
3. GitHub v0.1 发布页，录 4 秒；不要录入账号密码、通知、lockfile 或个人对局记录。
4. 安静环境单独录口播。软件音轨与麦克风分开保存，后期才压低音乐；不要用手机外放录音。

OBS 用“窗口采集”录软件，避免桌面杂物和任务栏。按显示器原生清晰度录制，1080p / 60fps 足够做本次主片；有更高分辨率原始素材再用于局部推近。硬件编码可用时优先使用，不要把低清素材放大后称作 4K。

OBS 官方建议 MKV 以降低异常中止导致整段损坏的风险，录完用“文件 → 录像转封装”转换为 MP4；无需重新压制。音频可选择独立轨道。[OBS 官方录制指南](https://obsproject.com/kb/standard-recording-output-guide)

## 剪辑风格

- 沿用软件的哨兵白、近黑、电蓝；画面干净，让音乐与真实操作成为重点。
- 中文大标题每屏 8–14 字；软件界面用局部推近，避免小字铺满屏幕。字幕放在稳定区域，不挡播放器和选中曲目。
- 分类切换用 6–10 帧的切片 / 遮罩转场；局部推近缓入缓出，避免每个镜头都抖动、旋转。
- 前 4 秒给记忆点，中段每 4–6 秒一个动作，结尾留 3 秒看清版本与下载位置。
- 可以用剪映、达芬奇或你熟悉的剪辑软件。先完成粗剪，再录口播和做字幕，最后统一配乐、响度与转场。

## 三个平台分别怎么发

这些是本次作品的编辑与导出选择，不是平台上传上限。

| 平台 | 推荐成片 | 内容重点 | 标题示例 |
| --- | --- | --- | --- |
| B站 | 60–75 秒，1920×1080 横版；需要时另做 2 分钟教程 | 怀旧开头 + 操作演示 + 下载与测试状态 | 我把 LOL 熟悉的开局音乐，做成了一个小工具 |
| 小黑盒 | 45–60 秒横版，配短图文 | 先说能解决什么，再给两张界面图、版本与实际边界 | 做了个 LOL 开场 / BP 音乐助手，v0.1 想请大家试试 |
| 小红书 | 35–45 秒，1080×1920 竖版；封面另做 1080×1440 | 情绪 + 桌面美感 + 一个最直观的操作 | 把熟悉的 LOL 开场旋律，带回下一局 |

竖版要重新构图：上方放一句大标题，中间放软件局部放大，下方留字幕区。不要把整个横版软件缩成一小块，更不要直接裁掉左侧分类或播放器。关键信息远离画面底边和右侧按钮区域，上传后看平台预览再确认。

横版封面：左侧大字“熟悉的开局音乐 / 回来了？”右侧软件实拍与一个正确年份的配图，下方小字“峡谷序曲 v0.1 测试版”。竖版封面只保留一句主标题与一个功能局部。

>
> 开场音乐和赛事 BP 分成两个入口，可以按分类、赛事和年份找音乐，也能收藏、导入本地音源、设置随机或固定播放计划。
>
> 目前是 v0.1 测试版；国服 / WeGame 的真实选人与实战自动触发仍需要继续验证，欢迎反馈兼容情况。部分年份没有找到合格音源，会保留空白。
>
> 项目与下载：https://github.com/CHO-CYQ/rift-music
>
> 你最想听回哪一年的开场？

标签按内容选择 3–5 个即可：英雄联盟、世界赛、开场音乐、BP音乐、桌面工具。发布前核对当个平台对链接、话题与展示位置的实际提示，不保证外链在所有界面都可点击。

## 音乐与内容真实性

“伴奏”不等于“免版权”。Riot 的 Creator-Safe 只覆盖指定曲目与用途，官方还单列了仅为宣传或销售产品 / 服务而使用音乐的限制。因此本片的长期背景配乐优先用原创或明确允许这类软件宣传的音乐；演示音轨也应核实对应使用许可，简介按适用要求写曲名、作者与链接。不要直接假定 STAR WALKIN 或任何世界赛主题都能随意用作宣传 BGM。[Riot 官方音乐使用指引](https://www.riotgames.com/en/riot-music-creator-safe-guidelines)

不要写“拳头官方软件”“保证不封号”“所有年份完整收录”。若使用 AI 生成的画面或配音，按投稿页当前要求如实标识；实际产品展示尽量使用真实录屏。
