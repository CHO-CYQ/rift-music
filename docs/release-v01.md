# v0.1 · 首次公开测试

日期：2026-10-27。Git 标签 `v0.1`，程序版本 `0.1.0-beta.2`，GitHub 标记为 Pre-release。

公开发布从 v0.1 开始，后续继续依据用户实测推进兼容与稳定性。

## 提供内容

- Windows x64 自包含程序，开场与 BP 两种独立用途。
- 148 首现有曲库（63 开场、85 BP），保留质量与来源标注。
- 分类、赛事、年份、搜索、收藏与本地导入；试听、片段、暂停、进度与音量。
- 独立自动播放计划、会话门控、托盘、单实例和任务栏工作区适配。
- 公开包为干净默认配置，不含开发者个人设置、对局记录或安装路径。
- 可选曲库：轻量程序内按分类多选下载，显示大小与进度，支持取消、SHA-256 校验和手动导入曲包，保留既有收藏与片段。

## 下载选择

推荐 `RiftMusic-v0.1-lite-win-x64.zip`，解压运行后打开左下角“下载曲库”，勾选需要的分类。希望一次装齐可选 `RiftMusic-v0.1-full-win-x64.zip`。

下载失败时，可在此页 Assets 手动下载 `RiftMusic-Music-…-v0.1.zip`，再在软件的下载窗口点击“导入曲包”，无需自己解压曲包。`Source code` 不含音频，也不能直接运行。下载曲包不会打开自动播放，安装后请先试听。

## 本轮调整

统一窗口、程序集、下载包与文档为 v0.1 测试版；整理首次公开的仓库快照，移除过期开发计划、旧发布说明和旧打包入口。当前音乐文件和本地个人设置不迁移、不重置。

## 已知边界

Windows 国服 / WeGame 的真实 BP 与游戏触发尚未完成实测。程序逻辑、模拟接口与桌面测试不能替代实战验证。

2021–2026 是可选范围，不代表每个赛区每年都有合格音源；空白组合保持空态。伴奏处理音轨可能仍有处理痕迹。

完整曲库列表恢复时仍可能出现短暂布局延迟；本版没有重构为虚拟化列表。部分高分辨率、多显示器切换场景仍需用户反馈。

## 反馈格式

Windows 与显示缩放 / 客户端与区服 / 操作步骤 / 预期与实际结果 / 可公开的错误截图。不要上传 lockfile、认证信息或未处理的个人对局记录。
